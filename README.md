# tech-corp


Employee Management System for TechCorp

TechCorp, a growing software development company, wants to develop a C# web application to manage employee records. The system should allow administrators to register employees, log in, and perform CRUD (Create, Read, Update, Delete) operations on employee data. The company has decided to implement the application using ASP.NET Core MVC, ensuring a secure and scalable system.

The employee details should include:

Employee ID
Full Name
Email Address
Job Title
Department
TechCorp also wants to implement authentication so that only registered administrators can access the system. The employee data should be stored in an in-memory list for now, with plans to integrate a database later.
